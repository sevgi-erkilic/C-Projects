# C Programlama Alıştırmaları

Bu depo, C dili öğrenme sürecimde yazdığım temel matematiksel hesaplama ve geometri projelerini içerir.

## Projeler Listesi:
* `daireAlaniVeCevresi.c` - Yarıçapı girilen dairenin alanı ve çevresi.
* `kure_hacim.c` - Yarıçapı girilen kürenin hacmi (Float bölme kuralı ile).
* `koni_hacim.c` - Taban yarıçapı ve yüksekliği girilen koninin hacmi.
* `silindir_yuzey_alani.c` - Silindirin toplam yüzey alanı hesabı.
## Operatör Kullanımı
* `and_operatoru.c` - and operatörü kullanımı
* `or_operatoru.c` or operatörü kullanımı
* `xor_operatoru.c` - xor operatörü kullanımı
* `right_shift_operatoru.c` - sağa kaydırma operatörü kullanımı
* `left_shift.c` - sola kaydırma operatörü kullanımı
